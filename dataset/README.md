# QuranicWords open dataset: Qur'anic Arabic vocabulary in 8 languages

The complete vocabulary taught by [QuranicWords](https://quranicwords.vercel.app/): **3,833
lemmas** that make up **97.4%** of the Qur'an's text (94,618 word occurrences), with their
**1,423 roots**, grammar, frequencies, curriculum position and meanings in **English, Bangla,
Urdu, Hindi, Indonesian, Turkish, Persian and French**. Every meaning is tied to a complete ayah,
with the exact character positions of the word in the Arabic and in the translation.

Use it for research, NLP, other learning apps, flashcard decks (Anki, Quizlet), word lists or
teaching material. You don't have to repeat the alignment and cleaning work behind it.

- Download: this folder, or `QuranicWords-dataset-v1.0.0.zip` on the
  [releases page](https://github.com/deanybytes/QuranicWords/releases/latest).
- Browse: every word has a page at <https://quranicwords.vercel.app/quran-words/> and every root
  at <https://quranicwords.vercel.app/quran-roots/>.
- Encoding: UTF-8. The CSV files start with a byte-order mark so spreadsheet apps show Arabic and
  the other scripts correctly.

## Files

| File | Records | Contents |
|---|---|---|
| `words.json` | 3,833 | one object per lemma (schema below), ordered by frequency rank |
| `words.csv` | 3,833 | the same words, one row each, with one meaning column per language |
| `roots.json` | 1,423 | every root with its words, ordered by total occurrences |
| `roots.csv` | 1,423 | the same roots, one row each |
| `verses.json` | 4,839 | every ayah that a sense cites: Uthmani text, word-by-word gloss and full translation in 8 languages |
| `metadata.json` | | counts, chapters, languages, translation editions, sources and their pinned sha256 |

The JSON files are arrays with one record per line, so they load with any JSON parser and still
diff line by line.

## `words.json` schema

```jsonc
{
  "id": "wv_5536bfac",          // stable id: wp_ particle / wv_ verb / wn_ noun + 8 hex digits
  "rank": 139,                   // frequency rank (1 = most frequent)
  "arabic": "خَافَ",              // vocalised lemma as taught
  "transliteration": "khāfa",    // academic Latin transliteration
  "root": "خ-و-ف",               // null for particles and some function words
  "category": "verb",            // particle | verb | noun
  "part_of_speech": null,        // particles/nouns: grammar label per language, e.g. {"en": "Preposition (Ḥarf Jarr)", …}
  "verb_form": {"form": "Form I", "label": {"en": "Form I", "bn": "রূপ ১ (فَعَلَ)", …},
                "past": "خَافَ", "present": "يَخَافُ", "masdar": null},   // verbs only; masdar when attested
  "occurrences": 83,             // occurrences in the Qur'an (Quranic Arabic Corpus)
  "curriculum": {"chapter": 2, "section": 1, "lesson": 7},
  "meaning": {"en": "fear", "bn": "ভয় কর", …},       // all senses joined with " / "
  "meaning_reviewed": {"en": true, …},              // false = fallback extraction, see below
  "senses": {
    "en": [{
      "meaning": "fear",
      "verse": "11:103",                 // surah:ayah, key into verses.json
      "word_index": 6,                   // 1-based word position in the ayah
      "arabic_span": [35, 40],           // [start, end) in verses.json arabic
      "translation_span": [39, 43],      // [start, end) in translation[lang], or null
      "word_by_word_span": [50, 54]      // [start, end) in word_by_word[lang]
    }],
    "bn": […], …
  },
  "url": "https://quranicwords.vercel.app/quran-words/khafa-5536bfac.html"
}
```

Spans are Python/JavaScript string indices (UTF-16 code units in JavaScript are the same here,
because all characters are in the Basic Multilingual Plane).

The language keys are `en bn ur hi in tr fa fr`. **`in` is Indonesian** (ISO 639-1 `id`); it
matches Android's legacy locale code used by the app.

## `verses.json` schema

```jsonc
{
  "verse": "11:103",
  "reference": "Hud 11:103",
  "arabic": "إِنَّ فِي ذَٰلِكَ لَأٓيَةٗ …",   // complete ayah, Uthmani script (GTAF tokens, checked against Tanzil)
  "word_by_word": {"en": "…", …},             // GTAF word-by-word glosses joined in reading order
  "translation": {"en": "…", …}               // full translation of the ayah
}
```

## How it was made

The dataset is generated by `tools/export/build_dataset.py` from the app's content, which the
reproducible pipeline in [`tools/pipeline`](../tools/pipeline/README.md) builds from pinned
sources:

1. The Quranic Arabic Corpus morphology gives every word's lemma, root, part of speech, verb form
   and segmentation, aligned word for word with the GTAF word-by-word translations.
2. For each lemma and language, only clean occurrences are used (the lemma without attached
   prepositions or pronouns), the glosses are cleaned (implied words, articles and subject
   pronouns removed) and the meanings are voted; a second meaning needs at least 25% of the votes.
   Up to 3 contextual senses per language are kept, each with at least 2 occurrences and a 15%
   share.
3. A lemma ships only if all 8 languages have a meaning that passes the fragment checks. Rejected
   lemmas are listed with reasons in `tools/pipeline/reports/excluded_lemmas.tsv`.
4. Every sense cites an ayah where that language's source translates the word with exactly that
   meaning. Every cited ayah is verified to be complete against the Tanzil Uthmani text.

`meaning_reviewed: false` marks meanings that came from the last-resort fallback (occurrences with
an attached pronoun, pronoun stripped). They are listed in
`tools/pipeline/reports/review_queue.tsv`; corrections are very welcome.

To rebuild from scratch:

```bash
python3 tools/pipeline/run.py
python3 tools/export/build_dataset.py --zip build/QuranicWords-dataset.zip
```
