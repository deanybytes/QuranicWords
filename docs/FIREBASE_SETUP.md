# 🗄️ Local-only design

QuranicWords is local-device-only by design. There is no sign-in, no remote database, and no server component anywhere in this codebase — progress lives entirely in an on-device Room database and DataStore preferences, and the app has everything it needs to run fully offline from first launch.

To carry progress across a reinstall or a new device, the Settings screen offers a **JSON export/import backup** (`BackupRepository`, `core/domain/repository/BackupRepository.kt` / `core/data/repository/BackupRepositoryImpl.kt`): exporting writes the learner's stats, lesson progress, and per-word attempt history to a file the learner picks via the Storage Access Framework; importing reads that file back in and adopts its user id as the device's local user id. No account, no network request, and no third-party service is involved at any point — see [`docs/USER_FLOWS.md`](USER_FLOWS.md) for the full export/import sequence and [`docs/DATA_MODEL.md`](DATA_MODEL.md) for exactly what the backup file contains.
